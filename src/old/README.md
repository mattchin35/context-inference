# Context-behavior models  
Behavior models for a context-based reward seeking task.   
  
Currently implemented:  
Stateless Q-learning  
Full State Q-learning  
Observation-based Q-learning  
HMM with Thompson sampling  
Logistic Regression (Beron et al 2022)
