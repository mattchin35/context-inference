## Proposed modules and contracts

Place the coordinating modules in a shallow package, src/neural_analysis/presentation_figures. Keep numerical libraries already used by the project (NumPy, pandas, scikit-learn and the existing CCA backend), existing neuroscience loaders, and Matplotlib. The offline path must import and run without starting Streamlit. No new dependency proposed.

- **preparation.py** exposes prepare_choices and make_block_splits. Prepare the needed window and width per analysis. Preserve trial and block IDs, original row, unit IDs, choice-relative bin edges in seconds, elapsed choice and delivery times, masks and region coverage. Population arrays have axes (choice, bin, unit), spikes/bin for prediction and CCA, Hz for decoding after division by bin duration in seconds.
- **decoding.py** exposes decode_region and score_choices for Figures 1-3. Select supervised rows and bins before fitting scaling or PCA. Reuse a training projection for its supported prefixes 1-10. Persist out-of-fold class probabilities with explicit class order, bin and trial summaries, reference scores, recovery counts and unavailable reasons.
- **replays.py** selects behavior-defined excerpts and prepares Figure 4 tracks. Reuse decoding functions with explicit excluded blocks. Hold out every block touched by a displayed excerpt, including its padding. Use one fitted model per region, target and width throughout the excerpt. Provide gaps outside supported windows and distinguish a missing delivery timestamp from an unrewarded choice.
- **prediction.py** exposes score_population_draw for Figure 5. Preserve source/target IDs, direction, draw, fold, size, rank and baseline. Store per-target model and baseline squared-error sums, support and labeled curve summaries. The four directions share matched draws and trial partitions. A rank unavailable at ten source PCs stays unavailable.
- **movement.py** exposes score_cca_blocks for Figure 6. Return paired scores, binned speed and units, block correlations, training sign anchors, support and selected interval. Keep undefined speed associations independent of valid neural coupling scores.
- **cohort.py** reads session summaries for Figures 7-8 from an explicit named roster. Validate compatible parameters, units, versions and bin widths. Session-specific unit counts and numerical ranks may differ. Average draws within session first. Take the Figure 8 median only at counts/ranks supported by every roster session. Preserve dates, missing reasons and the denominator even when a whole session lacks a panel.
- **results.py, plotting modules and entry points.** Save session intermediates as named arrays in versioned NPZ files under the session directory with a meta dictionary. Record producer, parameters, seed, axes, units, source identities, folds and versions. Plotting functions accept loaded results and return Matplotlib Figure objects. Split regional and interregional plots by responsibility as the panels grow. run_session and run_batch own paths, dry-run, cache selection and execution. A separate export_figures command takes a session or cohort manifest and output directory. A thin webapp view selects a saved run, panel, excerpt and width.

## Independent scientific review checks

Astra verifies these small cases directly against saved outputs. Use the same cases as test fixtures where practical.

- **Regional scores.** Native right=0, left=1. Replay right probability comes from the class-0 column. Four-state columns are left rewarded, right rewarded, left unrewarded, right unrewarded. Average within a complete choice first, then condition on its actual side. Binary probabilities of left [0.99, 0.40, 0.40, 0.40] produce one left prediction despite three right bin predictions. Compare overall and subgroup scores on identical held-out choices across training regimes. Preserve incomplete support in denominators. For all-unit accuracy 0.80 and PC scores [0.74,0.76,0.73,0.75,0.77], recovery is four PCs.
- **Prediction.** Compute matched size floor(min(good PFC,good HPC)/2). Check source/target IDs across all four directions and the target sets across every sweep. For one neuron, model error sums [2,4] and training-mean baseline sums [1,9] give R-squared 0.4. Recalculate one neuron from original held-out spike counts and fold training means. Keep negative scores and undefined zero denominators. Refit at the selected penalty on the outer training blocks. Reuse the existing alpha grid and tie rule, selecting on inner whole-block validation with the specified training-mean scoring. Record block IDs, purge counts, grid and chosen penalties.
- **CCA.** The speed loader returns UTC seconds and signed mm/s. Average absolute samples on half-open bin edges, retain coverage masks and leave empty bins unavailable. Neural CCA can use paired neural bins even where speed is missing. Flip both regional scores only using the training PFC-speed sign. Check that a joint flip preserves neural correlation and reverses both movement correlations. Report the held-out sign even if negative.
- **Cohort and replays.** Three available ten-PC sessions in a four-session roster produce three curves and no roster median. A switch excerpt spanning two blocks uses one fixed fit excluding both blocks and any additional padding blocks. Verify the 100-ms/500-ms selector changes the fitted result, preserves trial IDs, and keeps unsupported intervals blank.

## Figure delivery

Keep numerical packages free of UI dependencies. A plain session manifest plus per-analysis NPZ files is sufficient; share one figure renderer per static panel and one replay builder for both interactive surfaces. Avoid a plugin registry, new cache service or parallel plotting implementation.

The session command computes Figures 1-6 inputs. Batch runs the same command across named sessions and builds the Figure 7-8 cohort summary. A standalone export must work from saved results without the webapp or raw spikes. Export labeled PNGs by default, with separate main and backup panels, readable captions and named sessions. Return ordinary Figure objects for notebook or script reuse. Pass the chosen light/dark style into the renderer. Ask for the preferred theme before first rendering.

The webapp calls the same renderers for summaries and offers the same PNG for download. For live examples, provide a movable time cursor or playback over saved tracks, a 500/100-ms selector for Figure 4 and a full-sequence static frame. Use identical timestamps, data gaps, class colors and sign orientation in interactive and exported views. Figure 6 uses 100 ms. Provide an independently openable interactive replay (self-contained HTML using the existing Plotly dependency) with the same controls and a PNG still so the live examples also work outside Streamlit. Validate offline playback with networking disabled.

## Test-first implementation sequence

For each numbered slice, write the listed pytest tests first, run them with uv run, verify the intended failure and commit the tests before implementation. Implement the smallest passing slice, rerun related existing suites and refactor while green. Use existing fixtures in src/tests/neural_analysis for population decoding, communication subspace and session CCA. Add focused tests under presentation_figures.

1. **Inputs and splits.** Test mismatched regional trial coverage, good/MUA exclusion, units and bin counts at both widths, missing labels, immutable original IDs, shared folds and overlap purging. Test that a decoding trial with full narrow-window coverage survives missing wide-window coverage. Then implement preparation and a read-only cohort preflight.
2. **Regional scores.** Test a hand-calculated case where averaging probabilities gives a different choice score from averaging bin accuracy. Test four-state order, within-side reward scoring, missing classes, correct rewarded fit masks, shared test choices, fold-local PC prefixes and recovery after a dip. Perturb held-out rates and verify fitted transforms do not change. Deliver Figures 1-3 numerical results to the display owner.
3. **Replays.** Test both switch motifs and all four outcome states in one contiguous excerpt, joint block exclusion, one fit across a switch, actual delivery markers, gaps and identical trial IDs at both widths. Deliver Figure 4 tracks and event records to the display owner.
4. **Prediction.** Test disjoint matched draws, nested counts, original target units, inner/outer block isolation, feasible ranks and fixed ten-PC support. Hand-calculate per-neuron R-squared using two folds with different training means, unequal errors, negative scores and zero denominator. Check equal neuron weighting and both unrestricted references. Deliver Figure 5 numerical results.
5. **Movement.** Test signed velocity reversing within a bin, missing speed coverage, paired training-only sign flips, negative held-out movement correlation, undefined anchors, constant speed and fixed replay projection. Deliver Figure 6 numerical results and replay tracks.
6. **Cohort, export and webapp.** Test unequal unit/PC support, named sessions, a missing fourth session, unreached versus unavailable recovery, and full-roster medians. Test saved-result round trip, stale parameter invalidation, interrupted-run discovery, headless export, webapp routing and matching trace values across outputs. Verify a changed plot style reuses numerical results. Deliver Figures 7-8 and webapp integration.

## Performance and acceptance

Load shared counts once per required window/width per session. Reuse projections and ridge decompositions across supported prefixes or ranks only where training rows, tuning and feature sets coincide. Accumulate prediction error sums instead of retaining every target prediction for every rank. Use the saved session results for all display changes. Start with immutable run directories and a completion manifest written last. Defer a finer-grained resume scheduler until measured pilot cost justifies it. Parallelize across sessions within the CPU and memory budget, with a single worker per session and bounded numerical-library threads. Measure pilot time, peak memory and archive size before selecting batch concurrency.

First exercise all eight figures on a seeded synthetic cohort with known shared activity, choice and reward signals, and deliberately missing support. Next propose ct026 8/28 for the single-session pilot. Review numerical support, class counts, motif IDs, delivery timing, rank curves, replay gaps and exported slide readability with the user. After approval run the named ct026 8/3, 8/4, 8/10 and 8/28 cohort. Each analysis run writes its own dated and timed output directory outside version control with session IDs, parameters, warnings, elapsed time, script snapshots and a short scientific summary. Reuse compatible completed runs; changed inputs, version or parameters produce a new result. Do not present an unavailable motif or panel as a successful export.
