## Numerical contracts and first tests

1. **Inputs.** Keep original row, trial and block IDs, ordered units, masks, event timestamps, coverage and choice-relative bin edges in seconds. Counts have axes (choice, bin, unit) in spikes/bin. Divide by bin duration in seconds for decoding rates in Hz. Pass `population_quality="good"` and `missing_label_policy="exclude"` to the loader. Test joint coverage, manual/MUA exclusion, missing labels, units and both bin widths. A choice with two seconds of joint coverage can enter regional decoding even if it lacks the four seconds needed for prediction and CCA. Assign five whole-block folds before readout-specific filtering and verify overlap purging.
2. **Regional decoding.** Verify one unit of training weight per choice at both widths. Left probabilities [0.99, 0.40, 0.40, 0.40] yield one left choice prediction. Derive the pre/post summaries from the full-window fit. Check class order, four-state confusion row counts and normalization, and within-side reward scoring after averaging each choice's probabilities. Test correct-rewarded masks, identical held-out IDs across regimes and PC counts, and missing classes or required predictions. Perturb held-out rates and verify unchanged fitted transforms. Sweep integer PC counts through 30 on one training-fold PCA basis and reassess sustained recovery over every supported count. With all-unit accuracy 0.80 and PC scores [0.74, 0.76, 0.73, 0.75, 0.77], the sustained recovery count is four.
3. **Replays.** Test both switch rules, earliest ties, shortest four-state sequence and three-choice padding against original chronology. Check logged context entry, the first side-matched pump event for a rewarded choice, and a missing delivery timestamp. Verify one fixed fit per track across all excluded blocks. The 100/500-ms selector must load the fit for the selected width and average its saved probabilities by choice on the same trial IDs. Show one point per switch readout over [-1, +1) s and one four-class stacked bar per outcome over [0, +1) s. Test missing bins, class labels and the recorded event clock. Check that the binary tracks use class 0 for right.
4. **Prediction.** Use training-fold means and standard deviations for source and target counts. Fit unwhitened PCA on standardized source activity and feed its scores directly into ridge. Convert predictions back to spikes/bin for scoring. Fix `alpha = 0.1` in the sample-normalized objective. Test disjoint draws, nested sources, fixed target IDs, whole-block isolation, 30-PC support and equal neuron weighting. Unrestricted ridge on all supported PCs should reproduce the unit-input predictions within numerical tolerance. For Panel B, evaluate all supported PC counts through 30 and the larger source counts from A. Panel D uses a 30-PC input and both matched references. Maximum-rank regression should reproduce unrestricted ridge on the same inputs. For one neuron, model error sums [2, 4] and training-mean baseline error sums [1, 9] give R-squared 0.4. Include a negative result, a zero denominator, both unrestricted references and a missing fold to verify paired draw support.
5. **Movement.** Fit on the remaining blocks after purging overlaps with the held-out block. Test the time average of absolute signed velocity with unequal update durations, a bin entirely between updates and an incomplete bin. Test the joint training-derived sign flip, a negative held-out speed correlation, zero or undefined anchors and constant speed. Neural coupling remains reportable where defined. Verify the earliest tied speed increase and fixed projection for the four-choice replay.
6. **Cohort and delivery.** Verify all Figures 1-6 are computed or reused for each eligible session, including when another session supplies a presentation example. Distinguish unavailable results from unreached PC recovery. Three 30-PC curves in a four-session roster give 3-of-4 support and no roster median. Test saved-result round trips, interrupted-run discovery, stale inputs, style-only changes, headless PNG export, webapp routing and identical replay values in offline HTML and the app.

## Running and exporting

From the repository root, use the three module entry points below. A session list contains one metadata path per line. Relative paths are resolved against the list file. The batch command runs after pilot approval.

```sh
uv run python -m src.neural_analysis.presentation_figures.run_session --session-metadata /data/session/neural_session.json
uv run python -m src.neural_analysis.presentation_figures.export_figures --manifest /data/run/manifest.json --output-dir /data/run/figures --theme light
uv run python -m src.neural_analysis.presentation_figures.run_batch --session-list /data/sessions.txt --output-root /data/cohort/analysis_runs
uv run streamlit run src/neural_analysis/psth_webapp.py -- --session-metadata /data/session/neural_session.json
```

Select **PFC and HPC presentation figures** in the app. It discovers completed runs beside the session data and accepts a path to a saved cohort manifest. Both compute commands accept `--dry-run`, `--rerun` and `--seed`. Use `--workers` on the batch command to cap parallel sessions.

- **Compute.** `run_session` and `run_batch` support dry runs and reuse compatible completed results. Batch invokes the full session workflow for each named session and then builds the cohort summary. Share counts for each window/width (including the Figure 5/6 count tensor), PCA projections across prefixes, and one ridge decomposition across ranks for identical training inputs. Accumulate per-target error sums. Partition work across sessions with bounded numerical-library threads.
- **Save.** Write named NPZ arrays under the session directory with a `meta` dictionary recording producer, version, parameters, seed, axes, units, sources, folds and identities. Write a completion manifest last. Changed inputs, scientific parameters, version or an explicit rerun produce a new run. Keep timestamped run directories outside version control with script snapshots, session IDs, parameters, timings, warnings, log and scientific summary.
- **Display.** `export_figures` accepts a saved session or cohort manifest and output directory. Offer main and backup PNG panels with captions and return Matplotlib Figure objects. The Streamlit reader uses the same renderers and downloadable PNGs. Use one replay builder for the webapp and self-contained Plotly HTML, with a time cursor or playback, the Figure 4 width selector and a full-sequence PNG. Verify offline playback with networking disabled. Ask for a light or dark theme before the first render.
- **Accept.** Exercise all eight figures on a seeded synthetic cohort with known signals and deliberately missing support. After pilot designation, inspect numerical support, event timing, ranks, replay gaps and slide readability on August 28. Measure runtime, peak memory and archive size to choose batch concurrency. After user inspection and approval, process CT026 August 3, 4, 10 and 28, reusing the pilot where compatible. For the presentation, apply the spec's fallback order to the saved session-local examples.
