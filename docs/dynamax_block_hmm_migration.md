# Fixed exemplar block HMM migration

Block-state inference now uses ordered fixed exemplar models through Dynamax. `run_dynamax_block_analysis` models the supplied block/trial tables, and `run_multisession_analysis` models one joint concatenation. `SingleSessionAnalysisConfig` and `main_multisession` expose `block_exemplar_specs`, `exemplar_hmm_stay_prob` (default `0.9`), and `rerun_exemplar_hmm`. State indices follow the supplied model order. Default models are `expert_inf`, `expert_rl`, `naive_inf`, and `naive_rl`; their intercepts and residual SDs are in trials, and reward slopes are trials per previous rewarded trial. The sticky transition matrix distributes remaining mass equally across other models; parameters and transitions are fixed, not fitted. Trial GLM-HMM fitting remains deferred. Legacy state-count/seed/pickle-skip config fields are retained for caller compatibility and do not control fixed inference. The explicit `run_legacy_multisession_analysis` preserves the old learned-model workflow and requires optional `ssm` dependencies.

The single-session workflow smooths one session independently. The joint workflow smooths continuously across retained valid blocks, including session boundaries; each retained block contributes one transition. Existing history features remain their previously computed within-session values; histories are not recomputed across nights. Trial exports inherit `exemplar_hmm_smoothed_state`/`exemplar_hmm_smoothed_model` and `exemplar_hmm_smoothed_prob_<model>` as `inherited_block_strategy`, `inherited_block_model`, and `inherited_block_prob_<model>`, using explicit `cur_block`/`block_ix` and source-session identity. `inherited_block_bias` independently maps existing `bias_full_flag`. Block `inferred_strategy` aliases the new zero-based exemplar index. Full tables retain invalid rows with missing states; numerical arrays use compact valid-block positions. Plots label full-block ordinals separately from valid-block regression coordinates.

Numerical results are cached beneath each processed directory at `exemplar_hmm/fixed_exemplar_hmm_v1/<signature>/<UTC timestamp>/results.npz`. Exact parameters/model order, raw inputs, ordered source manifest (including empty sessions), source code, and package versions determine reuse. Reordering/adding/removing sessions invalidates the joint sequence. Conventional CSVs are archived by content before refresh; immutable runs retain named arrays, current block/trial snapshots, source/main/batch snapshots, metadata, summaries, and logs. Cache hits attach only modeled columns to current tables and rebuild inheritance, preserving fresh features in a new export record. Metadata distinguishes `numerical_artifact` from `export_record_directory` and reports `no_valid_blocks` when applicable. Joint outputs remain in the joint processed directory and do not overwrite independently modeled source-session tables. Old `ssm` pickles are untouched and not read normally; legacy grids require explicit model/module arguments.

The light-background diagnostic has separate panels for normalized residuals, log likelihoods, independent assignments, HMM-smoothed assignments, and posterior probabilities. It is saved under the session's `figure_path`, or directly under `cross_session_analysis` for joint runs; diagnostic and joint summary filenames are timestamped to preserve prior runs. Summary grids select fixed-model panels with `exemplar_model_names`; their layouts and other metrics are preserved. Collection-only and agreement-only modes still return before model inference, and context-block plus 10/20-valid-choice window analyses remain additive. Synthetic tests cover numerical mapping, invalid rows, cache behavior, and plots. No experimental session has been run in this migration; the next step is a user-designated single-session run followed by inspection and approval before any broader batch.
